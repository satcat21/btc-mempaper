# JavaScript / npm dependencies for OSV CVE scanning
#
# This project has no package.json and no Node build step -- all browser JS is
# either first-party (static/js/**, minified by tools/minify.py, pure stdlib)
# or vendored directly into the repo. This file is the hand-maintained
# inventory of the vendored third-party JS, in the same spirit as
# requirements.txt (PyPI) and apt-requirements.txt (Debian).
#
# Format: one "name@version" per line, npm ecosystem, "#" starts a comment.
# Keep versions exact -- OSV matches on a concrete version, not a range.
#
# When bumping a vendored file, update the version here in the same commit.
