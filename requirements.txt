# Held at 2.2.5 deliberately. From 2.2.6 onwards piwheels builds numpy on
# ARMv8 hardware and publishes the result under linux_armv6l and
# linux_armv7l filenames, so the wheel a 32-bit Pi installs holds
# instructions its CPU does not have. The device detects that and rebuilds
# from source, which takes most of a night on a Pi Zero. 2.2.5 is the newest
# release whose published wheel actually runs there. Debian trixie ships
# 2.2.4 for the same reason.
#
# Before raising it, install the candidate on an ARMv6 device and run
#   .venv/bin/python -m utils.wheel_platform
# Anything reporting 'built for ARMv8' costs every 32-bit device a source
# build; the dashboard keeps working through it, but it is not a quick
# update on that hardware.
