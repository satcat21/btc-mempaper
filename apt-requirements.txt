# System packages the installer and web updater keep installed.
#
#   imagemagick                 floats with the archive
#   python3-dev=3.13.5-1        pinned and held (apt-mark hold)
#
# A pinned package stops receiving Debian security updates, and the archive
# drops a pinned version the day a newer one replaces it. Pin only what breaks
# when it moves. Trixie is a stable release: a floating package only moves for
# security and bug fixes, never to a new upstream version. Pins apply only on
# the suite below; on any other they install floating. Check pins against the
# archive with tools/check_apt_pins.py. Details: utils/apt_requirements.py,
# docs/MAINTENANCE_GUIDE.md.
# pins-for: trixie
